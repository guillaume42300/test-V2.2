# Observateur Basket V2

Application native Android destinée à l'observation d'un match de basket.

## V2 incluse

- Fiche administrative du match
- Équipes, niveau, arbitres R1/R2
- Début de match
- Boutons FAUTE / VIOLATION / MÉCA / GESTION / AUTRE
- Dictée vocale avec bouton **J'AI FINI**
- Relance automatique de la reconnaissance vocale après une pause
- Détection des acteurs A1-A99, B1-B99, R1 et R2
- Vrai terrain de basket
- Acteurs déplaçables sur le terrain
- Fin de quart-temps Q1/Q2/Q3/Q4
- Historique local des matchs
- Rapport chronologique
- Synthèse structurée avec 2-3 points positifs et 2-3 axes de travail par arbitre

## Compilation GitHub Actions

Le workflow `.github/workflows/build.yml` construit automatiquement l'APK debug.
